# Electrician's Toolbox

## Our Mission
Build a professional, easy-to-use electrical toolbox designed for working electricians, apprentices, and contractors.

The app should make complicated electrical calculations and field problems quick and simple to solve.

## Core Design Principles

1. Extremely user-friendly interface.
2. Large buttons and readable text.
3. Minimal information required from the user.
4. Fast calculations with minimal navigation.
5. Core features work completely offline.
6. No unnecessary tracking or location permissions.
7. Occasional updates for electrical code references.
8. Accurate, independently verified calculations.

## Version 1 - Core Features

- Conduit bending calculator
- Conduit fill calculator
- Voltage drop calculator
- Ohm's Law calculator
- Three-phase electrical calculations
- Motor calculations
- Wire and conductor references
- Electrical color identification references

## Premium Features - Future Development

- AI Electrical Project Assistant
- Voice-controlled project descriptions
- Photo-based electrical installation analysis
- Smart Conduit Routing
- Automatic material takeoffs
- Saved electrical projects

## Privacy Philosophy

- No background location tracking.
- No unnecessary personal information.
- Core calculators function without internet access.
- User information remains private.

## Development Standards

- Verify all electrical calculations.
- Identify applicable electrical code editions.
- Clearly distinguish calculated results from estimates.
- Never present AI-generated recommendations as guaranteed code compliance.
- Prioritize safety and accuracy over convenience.
